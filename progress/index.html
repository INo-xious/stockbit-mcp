Drawing

Done

Levels, zones, trend lines, channels and markers drawn on the REAL Stockbit chart, by driving the browser you logged in with over CDP in a visible window; Stockbit's own auto-save persists them. The same geometry is also rendered as SVG and embedded in generated Pine. Saved layouts and their drawings are readable and writable over REST.

chartbit_analyze chartbit_draw chartbit_layout chartbit_layout_save chartbit_open chartbit_screenshot chartbit_study price_chart pine_script

Verified: The endpoints the chart page's own save adapter uses were read out of the current web bundle: /chartbit/charts and /chartbit/chart-drawings, content base64-ZIP of a single layout.json. The per-symbol pair this project targeted for months is a server-side stub and has been removed. Codec round-trip, shape mapping and the page scripts are tested; two tests drive a real Chromium when one is installed.

Alerts

Done

Rule engine sharing one indicator registry with the Pine emitter, so an alert and its alertcondition agree — plus a standalone daemon (`stockbit-alerts watch`) that polls during IDX hours and delivers. Three channels: an append-only JSONL log (always, written first), a native desktop notification (default on, no setup), and an optional https webhook. Fires once per bar; reports warm-up separately from a false condition.

alert_create alert_list alert_delete alert_check stockbit-alerts (CLI)

Verified: Live: two rules fired on BBRI with correct values (close 3020 > 2000; RSI 56.18 < 70), Windows toasts delivered, log written; the next pass fired 0, confirming same-bar suppression.

Workflow automation

Done

Five saved recipes — deep_dive, morning_scan, bandar_watch, alert_sweep, pine_handoff — each running several tools in one call, the same way every time. Declarative steps only: no eval, a closed template vocabulary, capped fan-out that reports what it skipped, and a failing step that aborts and names itself unless marked optional.

workflow_list workflow_run

Verified: Live: deep_dive on BBRI ran all four steps green in 3.7s (quote, technicals, chart, broker distribution).

Account writes

Done

Watchlist create, rename, delete, add, remove and favourite; screener save, delete and favourite. Each confirm-gated, verified by reading the account back, and logged. Deleting a watchlist that still holds symbols refuses once and names the count.

screener_delete screener_favorite screener_save watchlist_add watchlist_create watchlist_delete watchlist_favorite watchlist_remove watchlist_rename

Verified: Every edit reads the account back, so a wrong body shape reports not-visible rather than a false success. Nothing rolls back: each of these is one action a person can reverse in the Stockbit app, and undoing a change we could not read would be a second blind write.

Blocked on a decision

  • Chartbit writes are ENABLED under ADR-0003 with their full apparatus (snapshot, verify, rollback, mutation log) — and Stockbit's end discards them. Both POST routes answer 200 and store nothing; eliminated across nine variables, and their own web bundle has no save wiring either. Not a blocker this project can clear.
  • Composing brand-new drawings needs the TradingView line-tool schema (what `state` a LineToolHorzLine expects). Stockbit serves the charting library only to an authenticated chart page, so it could not be read the way the rest of the format was. Reading, round-tripping and modifying an existing layout does not need it.
